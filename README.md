# Comment Agent — AI-агент ответов на комментарии с контролем человеком

Прототип под реальное ТЗ с биржи FL.ru: агент собирает комментарии из
соцсетей (YouTube, Telegram, VK), LLM пишет черновик ответа, автор получает
карточку в единый Telegram-чат, подтверждает / правит / пропускает —
и агент публикует ответ в исходной соцсети.

## Архитектура

```
YouTube Data API ─┐
Telegram (Telethon) ├─> collectors ─> core ─> LLM-черновик ─> карточка в TG-чат автора
VK (каркас)      ─┘        │            (OpenAI-совм.)        [✅ Опубликовать]
                           v                                 [✏️ Править]
                        Storage (SQLite)                     [⏭ Пропустить]
                        антидубль, статусы                         │
                           ^                                       v
                           └────────── правка автора ◄──────── publisher
```

Принцип human-in-the-loop: ничего не публикуется без решения автора.
Правки автора сохраняются (`final_text`) — на этом массиве агент
дообучается под стиль автора (few-shot в промпт / файнтюн).

## Быстрый старт (демо без ключей и без Telegram)

```bash
python3 demo.py --auto   # автопрогон: публикация / правка / пропуск
python3 demo.py          # интерактивный режим
```

Демо проверено: 3 комментария собраны, черновики сгенерированы, решения
применены, повторный проход даёт 0 дублей.

### Пример реального прогона (`demo.py --auto`)

```
💬 demo · user_ivan
«Отличное видео! А можно подробнее про настройку на Windows?»
— Черновик LLM —
Спасибо за обратную связь! Рад, что материал оказался полезным...
[auto] решение автора: p  → ✅ опубликовано

💬 demo · maria_k
«Не работает ссылка в описании, поправьте пожалуйста»
[auto] решение автора: e  → ✏️ правка автора: «Спасибо! Ссылку поправил, проверьте.»

💬 demo · old_sub
«Смотрю вас с первого ролика, прогресс огромный 👏»
[auto] решение автора: s  → ⏭ пропущено

Повторный проход: новых комментариев 0 (антидубль работает)
```

## Боевой запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить TG_BOT_TOKEN, OWNER_CHAT_ID, ключи источников
python3 bot.py
```

- `TG_BOT_TOKEN` — от @BotFather, это интерфейс автора (карточки с кнопками).
- LLM — любой OpenAI-совместимый endpoint (OpenAI, GigaChat-прокси, Ollama);
  без ключа работает встроенный mock.
- Источники подключаются независимо: что заполнено в `.env`, то и работает.

## Маппинг на ТЗ заказчика

| Требование из ТЗ | Реализация |
|---|---|
| Собирать комментарии из соцсетей, YouTube, TG | `collectors.py`: YouTube Data API, Telethon; VK — по тому же интерфейсу |
| LLM сама пишет ответ на комментарий | `llm.py`: системный промпт + контекст поста |
| Пересылать комментарий + черновик в единый чат в ТГ | `bot.py`: карточка с текстом, автором, ссылкой |
| Автор может отредактировать или дать свой вариант | FSM «Править»: правка сохраняется как final_text |
| Команда опубликовать → ответ уходит в соцсеть | `publisher.py`: TG — через Bot API, YouTube — comments.insert |
| «Дообучается по ходу работы» | история правок в SQLite → few-shot примеры в промпт |

## Структура

```
agent/
  models.py      — Comment, Status, источники
  collectors.py  — сборщики (demo / YouTube / Telegram)
  llm.py         — генерация черновика (OpenAI-совм. + mock)
  storage.py     — SQLite: антидубль, статусы, правки автора
  core.py        — цикл: собрать → черновик → карточка
  publisher.py   — публикация ответа (log / TG / YouTube)
bot.py           — Telegram-интерфейс автора (aiogram 3)
demo.py          — прогон всего контура без внешних сервисов
```
